Pengaturan Webhook Google Apps Script

Masukkan URL Web App hasil penerapan skrip pada Google Spreadsheet Anda.

Diperoleh dari Google Sheets > Ekstensi > Apps Script > Terapkan (Deploy) > Aplikasi Web (Who has access: Anyone).

Mengalami Error "HTTP status 404"? Periksa 3 Hal Penting Ini:
  • Akhiran URL: Pastikan URL yang disalin berakhiran /exec (BUKAN /edit atau /dev).
  • Hak Akses Wajib "Anyone": Saat Deploy di Apps Script, opsi "Who has access" wajib dipilih "Anyone" (Siapa saja) agar server LMS dapat mengirim data.
  • Sudah Diterapkan (Deploy): Jangan hanya menekan Simpan (Ctrl+S), Anda wajib mengklik Deploy > New deployment > Web app.

Panduan Pemasangan & Skrip Siap Pakai

Hanya butuh 3 langkah mudah sekali seumur hidup untuk menghubungkan Google Sheets.

1 Buat Google Sheet

Buka sheets.new, beri nama file (misal: LMS_Infor_KKA_PJJ).

2 Tempel Kode di Apps Script

Klik menu Ekstensi > Apps Script, hapus kode bawaan, lalu paste kode yang telah disalin.

3 Deploy Aplikasi Web

Klik Deploy > New deployment > Web app. Pilih Who has access: Anyone. Salin URL-nya ke form di atas!
